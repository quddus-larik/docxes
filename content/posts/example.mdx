## Why Next.js?

- File-based routing with the App Router
- Server Components by default
- Built-in optimizations for images, fonts, and scripts

## Installation

```bash
npx create-next-app@latest my-app
```

## Creating Your First Route

Simply create a `page.tsx` file inside the `app` directory:

```tsx
export default function Page() {
  return <h1>Hello, Next.js!</h1>;
}
```

## Conclusion

Next.js 15 makes it easier than ever to ship performant, production-ready applications.
