# Styling with Tailwind CSS v4

Tailwind CSS v4 moves configuration from JavaScript to CSS, making theming more natural and performant.

## What's New?

- **CSS-first config** — define your theme with `@theme` in plain CSS
- **OKLCH color space** — perceptually uniform colors out of the box
- **Zero config** — works without a `tailwind.config.js` file

## Example Theme

```css
@import "tailwindcss";

@theme {
  --color-accent: oklch(0.7 0.15 200);
  --radius-lg: 1rem;
}
```

## Conclusion

Tailwind v4 keeps the utility-first workflow while embracing modern CSS features.
